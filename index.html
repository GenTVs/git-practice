Core Ideas

What this project helps you understand

GitHub collaboration becomes easier when you separate the ideas: local changes, branches, commits, remote branches, pull requests, and merges.

💻

Local Work

Your computer has its own copy of the repository. You can edit files, create commits, and experiment safely before publishing.

🌿

Branches

Branches are separate timelines. They let multiple people work on different features without breaking the main project.

☁️

Remote Repository

GitHub stores the shared online version. Pushing uploads your branch so others can review and merge your work.

🔀

Pull Requests

A Pull Request asks to merge one branch into another. It is the main conversation space for collaboration on GitHub.

GitHub Flow

From clone to merge

This is the common beginner-friendly workflow used in many GitHub projects.

01

Clone

Download the repository from GitHub to your computer.

git clone <repo-url>
02

Create Branch

Create a safe workspace for your change.

git switch -c version1
03

Edit Files

Make your HTML, CSS, or JavaScript changes in VS Code.

code .
04

Stage

Prepare changed files for the next commit.

git add .
05

Commit

Save a snapshot of your staged changes.

git commit -m "Add HTML and JS"
06

Push

Upload your branch to GitHub.

git push origin version1
07

Open Pull Request

Ask to merge your branch into main.

version1 → main
08

Merge

Combine approved changes into the main branch.

Merge pull request

Command Center

Git commands for this collaboration practice

These commands are written for Windows CMD. You can copy and practice them step by step.

CMD — GitHub Collaboration Practice

:: Clone repository
git clone https://github.com/GenTVs/git-collab-lab.git

:: Enter project folder
cd git-collab-lab

:: Create branch for HTML and JavaScript work
git switch -c version1

:: Open project in VS Code
code .

:: After editing files
git status
git add .
git commit -m "Add HTML and JavaScript structure"

:: Push branch to GitHub
git push origin version1

:: Later, after Pull Request is merged
git switch main
git pull

:: Delete local branch after merge
git branch -d version1

:: Delete remote branch after merge
git push --delete origin version1
